# Marts Models

Camada de modelos analíticos finais (marts) - tabelas agregadas para análises e BI.

Características:
- Tabelas materializadas para desempenho
- Lógica de negócio consolidada
- Dados prontos para relatórios e dashboards
- Dimensões e fatos relacionadas à expansão educacional
- KPIs e métricas calculadas
