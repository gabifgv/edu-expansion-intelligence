Fonte: síntese dos dados RAIS-MTE, INEP Censo Superior, IBGE Atlas ADH e CNPJ Receita Federal.  ·  Metodologia: cada uma das 4 dimensões combina 2 sub-indicadores normalizados (min-max) dentro do estado. Cidades com indústria pesada concentrada (ex: Embraer em Gavião Peixoto) podem aparecer no topo de D1 com D2 baixo — ler em conjunto.

Análise Executiva por IA

Claude opus-4-7 · ~15s · ~R$ 0,30 por análise
Síntese executiva pronta para decisão. Em 6 seções: perfil da cidade, mercado de trabalho, cursos recomendados (cruzamento setor→pós e graduação→pós), prospecção corporativa, parcerias acadêmicas e veredito estratégico (Prioridade Alta/Média/Baixa).
A IA recebe os dados dos blocos 1–6 + portfólio FGV (123 cursos) + base iMarket (600 cursos de concorrentes) e devolve recomendação acionável em parágrafos densos.

Fonte: Claude API (Anthropic) modelo claude-opus-4-7 + base interna FGV de portfólio + base iMarket de concorrentes.  ·  Metodologia: prompt engineering em 3 camadas — (1) Setor → Pós, (2) Graduação → Pós, (3) Gap de portfólio FGV vs concorrentes. SYSTEM prompt define persona de analista FGV; USER prompt inclui dados dos blocos 1-6 do município, lista completa de 123 cursos FGV ativos e 600 cursos únicos da base iMarket, cobrindo as instituições: ESPM, FDC, FDC Online, IBMEC, INSPER, InsperAltaGestao, MBA USP ESALQ, Mackenzie Alphaville, Mackenzie Campinas, Mackenzie Rio, Mackenzie São Paulo Higienópolis, PUC Minas, PUC RIO, PUC RIO ONLINE, PUC SP, PUCRS Online, SaintPaulAltaGestao e Mackenzie Brasília. Tokens médios: ~12k input + ~4.5k output.
