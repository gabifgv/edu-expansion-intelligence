7

Análise Executiva por IA

Claude opus-4-7 · ~15s · ~R$ 0,30 por análise
Síntese executiva pronta para decisão. Em 6 seções: perfil da cidade, mercado de trabalho, cursos recomendados (cruzamento setor→pós e graduação→pós), prospecção corporativa, parcerias acadêmicas e veredito estratégico (Prioridade Alta/Média/Baixa).
A IA recebe os dados dos blocos 1–6 + portfólio FGV (123 cursos) + 600 cursos de concorrentes e devolve recomendação acionável em parágrafos densos.

SYSTEM prompt define persona de analista FGV; USER prompt inclui dados dos blocos 1-6 do município, lista completa de 123 cursos FGV ativos e 600 cursos únicos de 18 escolas concorrentes (ESPM, Mackenzie, IBMEC, INSPER etc.). Tokens médios: ~12k input + ~4.5k output.
